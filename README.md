# N3 11 月底衝刺

純靜態 JLPT 複習 app。以 2026/11/4–11/30 的 27 天安排診斷、補強、限時整合與模考收尾。

- 通勤 25 分鐘、上班靜音 30 分鐘、晚間整合 35 分鐘；時間手動記錄。
- 保留原有單字／文法卡與 SRS。新增量 11/20 起減半、11/26 起歸零；到期量超過 40 減半、超過 80 暫停新增。
- 20 題分項診斷、每組 5 題練習、錯題原因與續做功能。診斷只是小樣本，不換算 JLPT 成績。
- 24 題原創情境題（文法 12、閱讀 6、聽力 6）是起始練習，並非完整模考題庫。完整應試練習請搭配首頁官方題本與音檔連結。
- 聽力使用系統日文合成語音，首次需主動開啟；答題後顯示逐字稿。語音可用性與離線能力依裝置而異。
- 上班入口會停止語音並關閉自動朗讀。進入聽力後仍需主動按播放才能開啟聲音。
- 進度保存在原有 `n3srs_v1` localStorage，可在設定匯出／匯入。新增 sprint 欄位，不重編原有卡片 ID。
- `practice-data.js` 為情境題庫；`sprint.js` 為課表與練習流程；`data.js` 為原始卡片。

本機啟動：`python3 -m http.server 8080`，開啟 http://localhost:8080 。

部署：沿用 `.github/workflows` 的 GitHub Pages 流程。Service Worker v2 會快取新增檔案；離線使用前需先線上載入一次。
